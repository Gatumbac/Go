## 1. ¿Un string garantiza UTF-8 válido?

No. Es bytes inmutables; valida con utf8.ValidString si el contrato lo exige.

## 2. ¿Una rune es un símbolo visual completo?

No necesariamente: los graphemes pueden agrupar varios code points.
