## 1. ¿Importas un module o un package?

Un package identificado por import path; el comando go resuelve el module que lo contiene.

## 2. ¿Por qué no crear muchos go.mod?

Introducen fronteras de resolución y publicación que no necesitas para separar ejemplos o responsabilidades internas.
