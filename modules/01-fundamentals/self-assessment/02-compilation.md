## 1. ¿Por qué go run tiene latencia antes de main?

Orquesta construcción y ejecución, usando caches si procede; esa latencia no representa solo el programa.

## 2. ¿El binario necesita el compilador?

No para ejecutarse, pero necesita destino compatible y posibles dependencias de enlace.
