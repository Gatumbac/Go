# Pistas · Estructura de un programa

[Enunciado](README.md)

Abre una por vez; no contienen implementación.

1. Relee el contrato: Crea un programa que salude a un nombre fijo mediante una función `message(name string) string`.

2. Usa este modelo como guía de razonamiento, no de implementación:

```text
package → imports → declarations
                       |
                       v
                 func main()
                       |
                       v
                 fmt.Println
```

3. Evita este error de la lección: Añadir argumentos a main. Escribe una predicción para una frontera antes de programar.
