Abre una por vez; no contienen implementación.

1. Relee el contrato: Define `type Meters float64` y `type Seconds float64`; escribe `Speed(distance Meters, elapsed Seconds) float64` para elapsed positivo.

2. Usa este modelo como guía de razonamiento, no de implementación:

```text
declaration → type + zero value
initializer → inferred or explicit type
conversion → new representation (check information loss)
```

3. Evita este error de la lección: Usar := fuera de funciones. Escribe una predicción para una frontera antes de programar.
