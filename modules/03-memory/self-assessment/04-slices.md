## 1. ¿Limitar cap elimina aliasing actual?

No, los elementos visibles se comparten hasta que copies o append obtenga otro array.

## 2. ¿Por qué un slice pequeño retiene mucho?

Puede mantener alcanzable el array subyacente grande.
