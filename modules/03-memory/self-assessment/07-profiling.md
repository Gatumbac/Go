## 1. ¿CPU profile explica todo timeout?

No. El proceso puede pasar el tiempo esperando I/O o locks.

## 2. ¿Menos asignaciones siempre mejora?

No. Importan latencia, throughput, memoria retenida, complejidad y carga real.
