## 1. ¿New garantiza heap?

No. Es una operación semántica; el compilador decide ubicación y puede optimizar.

## 2. ¿Scope determina cuándo GC libera?

No. La alcanzabilidad y decisiones del runtime importan; tampoco existe una garantía de liberación inmediata.
